# Download YouTube

## Descricao
Ferramenta para baixar videos e musicas do YouTube.

## Funcionalidades
- Download de videos
- Extracao de audio
- Multiplos formatos
- Qualidade configuravel

## Tecnologias
- Python
- yt-dlp

## Uso
```bash
python download.py --url "https://youtube.com/watch?v=..." --format mp4
```

## Instalacao
```bash
git clone https://github.com/Wsanbey/DONWLOAD-YTB.git
cd DONWLOAD-YTB
pip install -r requirements.txt
```
